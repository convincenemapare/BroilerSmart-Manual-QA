# BroilerSmart-Manual-QA
Project Overview

This project documents manual testing performed on BroilerSmart, an offline-first poultry batch management application.

The objective is to evaluate input validation, data handling, record persistence, and the application's response to invalid or unusual inputs.

Testing Scope

Batch creation and input validation

Bird quantity boundaries

Batch and supplier names

Data persistence

Record deletion behaviour

Testing Approach

Testing is performed manually using documented test cases. Each test records the steps, expected result, actual result, and outcome.

Potential defects are documented for investigation and are not treated as confirmed defects until the expected behaviour has been established and the issue reproduced.

Project Status

Testing and documentation are in progress.

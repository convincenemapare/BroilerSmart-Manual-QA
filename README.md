# Software Quality Assurance Portfolio

## About Me

I am an Information Technology student developing practical skills in software quality assurance. This portfolio documents my hands-on learning, testing activities, findings, and progress.

I focus on understanding software behaviour, investigating issues, designing test cases, and communicating findings clearly.

## Project Under Test

BroilerSmart is an offline-first poultry batch management mobile application.

This project is my practical testing environment. I use it to investigate input validation, data handling, persistence, calculations, and application behaviour.

## My Testing Approach

I use structured testing and exploratory testing to investigate software behaviour.

My work includes:

- Test case design
- Exploratory testing
- Input validation and boundary testing
- Test execution and documentation
- Defect investigation and reporting
- Evidence collection
- API testing fundamentals

I distinguish confirmed defects from observations, questions, and improvement recommendations.

## Evidence and Transparency

I document findings based on observed behaviour and available evidence.

Where expected behaviour is unclear or a result has not been verified, I identify it as an observation or an item requiring further investigation.

This portfolio is a work in progress and reflects my ongoing development in software quality assurance.
